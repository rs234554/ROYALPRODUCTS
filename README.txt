# RoyalNova Customer + Admin

## Important
This starter uses browser localStorage for products/orders and a UPI deep link for payment.
UPI ID: Royalnovaenter@naviaxis

### Files
- customer/index.html — customer shop
- admin/index.html — admin panel

### GitHub Pages
Upload the `customer` and `admin` folders to your repository. Open:
`/customer/` for customers and `/admin/` for admin.

### Admin login
Default password: `admin123`
Change it in `admin/index.html` before publishing.

### Important limitation
This version is a front-end starter. localStorage is browser/device-specific, so customer orders will NOT automatically appear in the admin panel across different phones. For a real online store, connect a backend/database and a payment gateway/payment verification system.
